## 修复

| 原问题 | 处理 |
| --- | --- |
| 伴生服务访问不存在的 `this.settings` | 使用已安装 ZML 导出的 `settingsLib` |
| 星期按钮仅改变内存状态，未触发重绘 | 通过独立 UI 设置键触发设置页重建 |
| 空课表同步后不创建列表，清空后列表无法恢复显示 | 补齐创建和可见性切换 |
| 列表类型范围结束索引越界 | 使用最后一条数据的索引 |
| 应用退出用启动时的旧数据覆盖新缓存 | 由页面同步时保存，退出不再覆盖 |
| 缓存不存在、读取异常或 JSON 非对象 | 安全回退为空数据 |
| 批量导入接受 null、数组或无效课程 | 共用结构校验，明确点击导入并显示结果 |
| 错误的手机数据返回空课表 | 返回错误，手表保留已有缓存 |
| 推送异常未捕获，异步响应可能更新已销毁页面 | 等待并捕获推送错误，页面销毁后忽略响应 |
| 排序改变原数据数组 | 排序副本 |

ZML 0.0.9 已自动注册并移除 `onSettingsChange` 监听，无需重复注册。校验仅约束星期、课程对象、已知字段类型和非空时间格式；未新增课程提醒、学期/单双周、跨日课程等功能。
